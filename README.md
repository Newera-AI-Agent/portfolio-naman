# Naman Soni — Portfolio

A personal portfolio for Naman Soni, creator and builder of LND AI, Talk AI Companion, NewEra AI Agent, and other AI product experiments.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Local shadcn/ui-style `Button` and `Badge` primitives

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run lint
npm run build
npm start
```

The only social and collaboration path represented on the site is [GitHub](https://github.com/namansoni78).
